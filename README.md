## Featured Projects

### AWS S3 Security Auditor | Cloud Security

**Python, boto3, AWS S3, AWS IAM, Security Control Auditing, Excel Reporting**

Developed a read only Python security auditing tool that evaluates AWS S3 buckets against seven security controls, including public exposure, Block Public Access, encryption, versioning, logging, bucket policies, and MFA Delete.

I designed a per bucket scoring system and structured Excel reporting to make security findings easier to review and compare. During testing, I identified and remediated a publicly exposed S3 bucket by enforcing Block Public Access and applying least privilege IAM controls.

---

### Auth Log Analyzer | Detection Engineering

**Python, Linux Authentication Logs, Log Analysis, Threat Detection**

Developed a Python based authentication log analysis tool that identifies patterns associated with brute force activity using a configurable sliding window algorithm.

The default detection logic identifies five failed authentication attempts within 120 seconds and correlates those failures with subsequent successful logins and off hours activity. I validated the detection logic against real authentication logs to evaluate how these patterns could indicate possible account compromise.

---

### Web Application Vulnerability Remediation | Application Security

**SQL, JavaScript, OWASP Top 10, CSP, Anti CSRF Tokens, Secure Software Engineering**

Performed vulnerability testing and remediation across the CampusSwap and GreenThumb web applications.

I reproduced SQL injection authentication bypass, UNION based SQL injection, stored XSS, reflected XSS, DOM based XSS, and CSRF vulnerabilities.

I then implemented mitigations using parameterized queries, output encoding, Content Security Policy, anti CSRF tokens, and hardened cookie settings. I also developed exploit scripts to reproduce attack behavior before remediation and verify that the implemented fixes were effective afterward.
